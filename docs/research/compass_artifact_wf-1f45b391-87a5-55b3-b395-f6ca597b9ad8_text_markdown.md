# SNS株情報インフルエンサーの「後出し的中誇示→DM勧誘」スキーム：性質・法的リスクと「Stock Radar」との比較

## TL;DR
- Threadsで見かける「明日急騰する銘柄予告→翌日『全部ストップ高』と誇示→フォロー＋DM『銘柄』で個別配布」という投稿は、日本の当局が繰り返し注意喚起している「SNS型投資詐欺」「無登録の投資助言・情報商材勧誘」の典型的な入口構造であり、①後出しで当たった結果だけを見せる生存者バイアス型の実績誇示、②有償の個別助言に進めば無登録の投資助言・代理業（金商法違反）、③自己保有株を煽って売り抜ければ相場操縦・風説の流布に該当し得る、という三重のリスクを内包する。
- 有償で特定銘柄の売買を助言することは「投資助言・代理業」の登録（金商法29条）を要し、無登録なら5年以下の拘禁刑（旧・懲役）または500万円以下の罰金の対象。無料のSNS投稿は現行法では規制が及びにくいが、「DMで個別・有償」に移行した瞬間に登録要件（対価性・特定性・業＝継続性）が揃いやすい。
- ユーザーの「Stock Radar」は、公開情報（TDnet適時開示）を情報源とし、検証可能で、金銭勧誘・販売・自動売買を一切行わない個人用分析ツールである点で、上記スキームとは情報源の透明性・検証可能性・対価性・勧誘性のすべてにおいて構造的に異なり、投資助言・代理業の登録要件（対価性を伴う他者への助言契約）を原則満たさない。

## Key Findings

**1. 当局の注意喚起の対象そのものである。** 金融庁・証券取引等監視委員会（証券監視委）・警察庁・消費者庁・国民生活センターは、「SNSで儲かる投稿→DM/LINE誘導→有料情報・投資勧誘」という導線を「SNS型投資詐欺」「無登録業者による投資勧誘」として繰り返し警告している。金融庁は「SNS上の投資詐欺が疑われる広告等に関する情報受付窓口」を設置し、証券監視委は消費者法ニュース（2025年4月）で「株価上昇が見込まれる銘柄を教える等として、報酬を受け取って投資助言を行うこと」を無登録なら違法な行為の代表例として明示している。

**2. 「後出し的中」は生存者バイアスと検証不能性で成り立つ。** 予告を見せず結果だけを後から誇示する、複数銘柄をばらまいて当たった分だけ残す、外れた投稿を削除する、といった手法により、的中率は原理的に検証できない。競馬・スポーツ予想詐欺で古くから知られる「分割配信型」（対象を分けて異なる予想を送り、当たった相手にだけ次を売る）と同じ構造で、株情報でも同型が横行している。

**3. 無料のSNS発信は規制が及びにくいが、有償の個別助言は登録が必要になり得る。** 金商法2条8項11号・28条3項が定める「投資助言・代理業」は、①対価性（報酬）、②特定性（特定有価証券の価値・投資判断に関する助言）、③業（反復継続）の3要件で判断される。不特定多数に無料で「上がる」と言う投稿だけでは要件を欠くが、フォロワーをDMに誘導して有償で個別銘柄を助言すれば3要件が揃い、無登録営業に該当し得る。

**4. 自己の保有株を煽って売り抜ければ相場操縦・風説の流布。** 合理的根拠のない情報で株価変動を図る投稿は金商法158条（風説の流布）、取引を誘引して相場を変動させる行為は159条（相場操縦）に該当し得る。

## Details

### スキームの性質（何が起きているか）

観察された投稿パターン——「明日急騰する銘柄を予告」→翌日「全部ストップ高でした！」と結果を誇示→「フォロー＋DMで『銘柄』と送って」と個別誘導——は、当局・弁護士・証券会社が警告する典型的な導線を組み合わせたものである。

- **入口（無料の実績誇示）**：SNS上で「儲かる」実績や的中を見せてフォロワー・興味を集める。金融庁と警察庁は、SNS・バナー広告・DMで関心を持たせ、LINE等のクローズドな場へ誘導し、そこで投資資金・情報商材費・セミナー料等を要求する流れを「SNS型投資詐欺」の代表的手口として説明している。
- **誘導（DM→クローズド空間）**：DMやLINEグループへ移し、「先生」「アシスタント」役が講義・銘柄配布を行う運用は実際に相談が寄せられている（日経記事や証券会社PDFのコピペ講義、芸能人画像の流用など）。
- **収益化（有料情報・サロン・商材）**：オンラインサロン会費、有料note/メルマガ、情報商材、コンサル契約などで課金する。国民生活センターは「1日数分で月数百万円」「◯万円が◯億円になる投資法」といった情報商材トラブルの急増を報告しており、副業・投資系トラブルの平均契約購入金額は2020年度の27万9,519円から2023年度に76万3,117円、2024年度は7月末時点で105万9,658円へと急増している。

このスキームは必ずしも全件が「詐欺罪」に問えるわけではないが、（a）生存者バイアス型の誇大な実績表示、（b）無登録投資助言、（c）情報商材・サロン勧誘、（d）相場操縦・風説の流布、のいずれか（しばしば複数）のリスクを帯びる。

### 1. 金融庁・証券監視委等の注意喚起と実例

- **金融庁**：「詐欺的な投資勧誘等にご注意ください！」「SNS・マッチングアプリ等で知り合った者や著名人を騙る者からの投資勧誘等にご注意ください！」等のページを設置。2024年6月には犯罪対策閣僚会議が「国民を詐欺から守るための総合対策」を策定し、これを受けて金融庁は「SNS上の投資詐欺が疑われる広告等に関する情報受付窓口」を開設。「偽広告等をきっかけに投資や有料の投資アドバイスの勧誘を受けた」事例を受け付けている。
- **証券監視委（消費者法ニュース№143, 2025年4月、証券検査課課長補佐 青山亮）**：無登録で違法となる行為として「株価上昇が見込まれる銘柄を教える等として、報酬を受け取って投資助言を行うこと」を明記。無登録業者に対し警告書発出・公表、裁判所への禁止/停止命令の申立てを行うと説明。
- **金融行政方針**：金融庁は2024事務年度金融行政方針で「SNS型投資詐欺等への対応」を掲げ監視を強化。証券監視委はAIでSNS投稿と株価を突合し、あおり投稿を抽出する監視体制を整備してきた（日経報道）。さらに、無登録業者を立件しやすくするため証券監視委に犯則調査権限を創設する法改正が検討されていると報じられている（日経）。※これは検討段階の報道であり確定した制度ではない。
- **警察庁の被害統計**：SNS型投資・ロマンス詐欺の被害は過去最悪水準。警察庁「令和7年における特殊詐欺及びSNS型投資・ロマンス詐欺の認知・検挙状況等について（確定値）」（組織犯罪対策第二課・生活安全企画課、令和8年5月22日）によれば、令和7年（2025年）のSNS型投資詐欺は認知件数9,523件（前年比+3,110件、+48.5%）、被害額1,288.0億円（前年比+416.9億円、+47.9%）。当初の接触手段はバナー等広告が3,785件、ダイレクトメッセージが3,549件で、これらが全体の約8割を占める。SNS型投資・ロマンス詐欺全体の既遂1件当たり被害額は1,213.3万円（前年比−29.4万円）と明示されている（SNS型投資詐欺単独の1件当たり平均は本文には明示されず、認知件数と被害額から約1,353万円と算出される）。
- **消費者庁・国民生活センター**：情報商材トラブル（副業・投資の儲け話）や、無登録業者がSNS・セミナーで若年者に借金させて投資させる被害を注意喚起。
- **実際の相談例**：X（旧Twitter）で投資に詳しそうなアカウントをフォロー→DMでLINE登録を促され→「先生」「アシスタント」による銘柄配布・講義、という相談がYahoo!ファイナンスに寄せられており、講義内容が日経記事や証券会社PDFのコピペ、アシスタント画像が芸能人の流用であった例が報告されている。

**関連する無登録・不公正取引の摘発事例（性質理解のための実例）**：
- **FXミラートレード無登録助言事件**：投資スクール運営会社「アーニングアカデミー」代表・浜本学泰（51）、FX事業会社の実質経営者・岩井崇（47）ら男4人が、2024年11月12日に金商法違反（無登録営業）容疑で警視庁生活経済課に逮捕された。2019年3月〜2023年11月に約1,500人から約16億円を集め、ミラートレード（自動コピー取引）で「専門家に任せれば確実に利益」と勧誘したとされる（朝日新聞報道）。
- **海外金融商品の無登録勧誘**：「STERLING HOUSE TRUST（スターリングハウストラスト）」（元本保証・毎月出資金1%＝年12%配当をうたう）を、2015年3月〜2024年5月に約1万9,900人へ無登録勧誘し計約806億円を集めたとして、証券監視委が2024年6月25日に東京地裁へ禁止・停止命令を申立て、同年10月31日に発令された（証券監視委・日経）。
- **自社株の無登録勧誘**：東京都港区のコンサルティング会社幹部の男（39）ら男女6人が、「月利15%」などとうたって自社株購入を無登録で勧誘したとして、金商法違反（無登録営業）容疑で警視庁生活経済課に逮捕された（約2.7億円集金か、2024年11月6日日経報道）。
- なお、「株式の銘柄推奨をSNS等で有償提供する無登録の投資助言・代理業」そのものを対象にした証券監視委の裁判所申立て・刑事告発の明確な公表例は、2023〜2025年の公表リストでは確認できなかった。株式銘柄推奨型はむしろ登録業者への行政処分（例：投資情報誌広告からの電話勧誘で投資助言を行っていた「やまびこ投資顧問」への2026年の行政処分勧告で無登録助言業務への加担が問題化）や、警察の刑事摘発で扱われる傾向がある。

### 2. 「後出し的中」投稿の統計的・心理的性質

- **生存者バイアス（サバイバーシップ・バイアス）**：成功例だけが可視化され、失敗例が消えることで全体像を誤認する現象。投資の世界では、運用成績集計時に「途中で消えたファンド」を除くと平均リターンが実態より高く出る現象として広く知られる（統計教室・和からの解説）。SNSでは「儲かった」投稿は拡散されやすく「損した」投稿は出にくいため、「みんな儲かっている」ように見える（かぶ1000氏のDiamond記事等でも指摘）。予告を見せず結果だけ誇示する手法は、この偏りを意図的に作り出す。
- **検証不能性**：事前の予告全件と事後結果の対応関係が公開されないため、的中率を第三者が検証できない。外れた投稿の削除、当たった投稿のみのスクショ提示で、見かけの的中率をいくらでも操作できる。悪質競馬予想サイトの解説では「外れた買い目を捏造し的中実績として掲載」「販売していない有料プランの的中実績を掲載」といった手口が指摘されており、株情報でも同型の実績捏造が可能である。
- **複数提示・分割配信（後出しじゃんけん型）**：多数の銘柄を提示し当たった分だけ残す、あるいはフォロワー群を分割して別々の予想を送り、結果的に「当たった」グループにだけ次を売り込む手法。競馬・ギャンブル予想詐欺で古典的に知られ（対象者を分けて逆の予想を送る等）、株情報でも同型が用いられる。「本当に上がる情報があるなら他人に売らず自分で使うはず」という指摘（競馬予想詐欺解説）は株にもそのまま当てはまる。
- **心理的操作**：「限定」「今だけ」「あなただけ」による特別感・緊急性、少額の初期的中で信頼を作り高額プランへ誘導する段階的手法、権威（先生・専門家・著名人）の演出。警察庁・ALSOK等が「巧妙な偽プロフィール」「段階的な信頼構築」「心理的操作」「複数プラットフォーム利用」を特徴として挙げている。

### 3. 金商法上の一般的整理（投資助言・代理業の登録要否）

※以下は一般的な制度説明であり、個別事案の法的判断ではない。

- **定義**：金商法2条8項11号は、有価証券の価値等（イ）または金融商品の価値等の分析に基づく投資判断（ロ）について、口頭・文書その他の方法で助言することを約し、相手方が報酬を支払うことを約する契約（投資顧問契約）を締結し、これに基づき助言を業として行うことを「投資助言」と定め、28条3項がこれを「投資助言・代理業」と位置づける。
- **3要件**：実務上、①対価性（会費・購読料・情報料等の報酬）、②特定性（特定銘柄の売買・価値等への具体的助言）、③業（反復継続）のすべてを満たすと登録が必要とされる。29条により登録なしの営業は禁止、無登録営業は5年以下の拘禁刑（旧・懲役、令和7年6月1日以降は拘禁刑）または500万円以下の罰金（併科あり）。
- **除外**：「不特定多数の者に販売する目的で発行され、不特定多数が随時購入可能な」新聞・雑誌・書籍等での一般的情報提供は投資顧問契約の定義から除かれる。
- **本スキームへの当てはめ（一般論）**：
  - 不特定多数に向けた無料のSNS投稿で「この銘柄が上がる」と言うだけでは、対価性・契約性を欠き、投資助言・代理業には当たりにくい（現行法ではSNS上の無料投稿への規制は及びにくいと専門家も指摘）。ただし無料でも、自己保有株の売り抜け目的で虚偽・無根拠の情報を流せば風説の流布・相場操縦の問題となる。
  - フォロワーをDMに誘導し、有償（サロン会費・情報料・個別コンサル料等）で特定銘柄の売買を助言する段階に至れば、3要件が揃い、無登録の投資助言・代理業に該当する可能性が高い。「最初は無料、途中から有料の個別助言」への移行時点で登録が必要になる、というのが実務家の一致した整理。
  - 顧客資金を預かって運用すればさらに重い「投資運用業」、自動売買のコピー提供も助言/運用業に該当し得る（FXミラートレード事件）。

### 「Stock Radar」との構造比較

| 観点 | SNS「後出し的中→DM勧誘」型 | Stock Radar（ユーザーの設計） |
|---|---|---|
| 情報源の透明性 | 不明・非公開（「独自情報」「仕手情報」等、根拠不明） | TDnet適時開示という公開・公式の一次情報。誰でも検証可能 |
| 検証可能性 | 予告全件が非公開で的中率検証不能。生存者バイアス前提 | スコアリング基準とデータ源が明示可能で、事後検証が可能 |
| 対価性（報酬） | サロン・情報商材・個別助言で課金＝対価性あり | 金銭勧誘・販売なし＝対価性なし |
| 助言の相手方・契約 | 不特定多数を集め個別に有償助言（投資顧問契約化） | 個人用ツールで最終判断は本人。第三者との助言契約なし |
| 勧誘性 | フォロー＋DM誘導で積極勧誘 | SNSでの勧誘・販売を一切行わない |
| 自動売買 | コピートレード等を伴う例あり（運用業リスク） | 自動売買なし。人間が最終判断 |
| 相場操縦・風説リスク | 煽り→売り抜けでリスク大 | 自己の分析・自己判断で、他者を誘引・煽動しない限り低い |

この比較から、Stock Radarは投資助言・代理業の登録要件（対価性を伴う他者への助言契約＝投資顧問契約）を原則満たさず、情報源・検証可能性・非勧誘性の点で当局が問題視するスキームとは構造的に別物であると整理できる。TDnetは東京証券取引所が運営する適時開示情報伝達システムで、上場企業が投資判断上重要な情報を公平に開示する公式インフラであり、開示資料は一定期間JPXサイト上で無料閲覧できる。公開・公式の一次情報をスコアリングする点は、根拠不明の「独自情報」を売る型とは対極にある。

## Recommendations

**一般利用者（こうした投稿を見たとき）**
1. DM・LINE誘導には応じない。金融庁「免許・許可・登録等を受けている業者一覧」（search.fsa.go.jp）で登録を確認し、無登録なら関わらない。
2. 「全部ストップ高」等の実績は予告全件が示されない限り検証不能と考える。「必ず」「あなただけ」「限定」は危険信号。
3. 被害・疑わしい広告は金融庁「SNS上の投資詐欺が疑われる広告等に関する情報受付窓口」、証券監視委情報提供窓口（0570-00-3581）、消費生活センター（188）へ。

**発信を行う側（合法ラインの目安）**
1. 有償で特定銘柄の売買判断を助言するなら投資助言・代理業の登録が必須。無登録での有料サロン・メルマガ・個別DM助言は避ける。
2. 無料でも、保有株を煽って売り抜ける行為は相場操縦・風説の流布に該当し得るため厳禁。

**Stock Radarの設計者（ユーザー）への具体的指針**
1. 現行設計（TDnet公開情報のスコアリング＋人間の最終判断＋SNS勧誘・販売・自動売買なし＋個人利用）を維持する限り、投資助言・代理業の登録は原則不要と整理できる。透明性・検証可能性・非対価性が「守るべき一線」。
2. **登録が必要になり得る閾値（レッドライン）**：
   - スコアや推奨銘柄を有償で第三者に提供し始める（対価性＋特定性＋業）。
   - 無料でも特定個人向けにDM等で継続的に個別銘柄助言を行う。
   - 出力に基づき自動発注・コピートレードを他者に提供する（助言業/運用業）。
   これらのいずれかに触れる場合は、事前に財務局への相談・弁護士確認・登録要否の精査を行う。
3. 仮に将来的に外部提供する場合でも、（a）不特定多数が随時購入可能な形の一般情報にとどめる、（b）個別銘柄の売買判断助言と対価を結びつけない、（c）「必ず上がる」等の断定的表現を用いない、を徹底する。
